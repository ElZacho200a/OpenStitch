Bobines

    Glisser pour changer l'ordre de couture, ou Alt+↑/↓.

    Clic sélectionner · Clic droit ou appui long : menu radial (1–8 au clavier) · glisser un nom de champ pour régler · L loupe. Mode Nœuds : le tracé change vraiment.
