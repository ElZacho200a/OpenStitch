# Polices intégrées

`Vera.ttf` et `VeraBd.ttf` : Bitstream Vera Sans (Roman, Gras), licence permissive dans
`bitstream-vera-license.txt` (redistribution libre ; les polices ne doivent pas être vendues
seules et un dérivé ne peut porter « Bitstream » ni « Vera » dans son nom). Utilisées par le
lettrage (`apps/desktop/lettering_fonts.qrc`) et par les tests (`tests/unit/lettering`).
